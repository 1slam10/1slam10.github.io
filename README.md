# Link-in-Bio Page

A minimalist link-in-bio webpage showcasing your social media accounts with a modern, clean design. This page features:

- 🎨 Ant Design-inspired UI components
- 📱 Fully responsive design for all device sizes
- 🌓 Automatic theme detection based on system preferences
- 👨‍💻 Coding-style interface with monospace font and command-line aesthetics
- ⚙️ Easy configuration via a single config file

## Features

- Clean, minimalist design that focuses on your content
- Automatic dark/light mode based on user's system preferences
- Responsive layout that works on mobile, tablet, and desktop
- Centralized configuration - update all your information in one place
- Custom animations for interactive elements

## Customization

To customize this page for your own use:

1. Edit the `js/config.js` file to update your personal information and social links
2. Replace the avatar image in `assets/avatar.svg` with your own profile picture
3. Optionally modify the CSS styles in `css/styles.css` to match your personal brand
